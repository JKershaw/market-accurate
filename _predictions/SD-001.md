# SD-001: AI-code security gap persists

**Status:** 🟡 Pending

**Headline:** A controlled 2026 benchmark will still show AI-generated code introducing security vulnerabilities in at least 30% of tasks.

**Why this matters:** Reliability, not capability, is the thesis's claimed bottleneck for autonomous software production; a persistent high defect rate is the most direct test of it.

---

## Full claim

A controlled AI-code-security benchmark published in 2026 will still show AI-generated code introducing security vulnerabilities in at least 30% of tasks.

## Threshold

The next Veracode GenAI Code Security Report (or an equivalent controlled, multi-model benchmark — not field telemetry) published by Feb 28, 2027 shows AI-generated code introducing an OWASP-class vulnerability in ≥30% of evaluated tasks. Series = controlled benchmark, not PR/field telemetry; metric = % of tasks with an injected vulnerability.

## Base rate

Veracode's Oct 2025 report found 45% of tasks introduced a vulnerability and that newer/larger models did not improve security. Base-rate probability the rate stays ≥30% in the next iteration: ~75%.
